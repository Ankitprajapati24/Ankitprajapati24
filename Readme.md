## Three problems I've built around

### 01 / Can a backend start with a description?

**[Backend Pilot](https://backendpilot.onrender.com/)** takes natural-language requirements and generates backend API code, project structure, and tests. I built prompt pipelines and structured outputs to organize what the LLM produces.

`LLM applications` `Groq APIs` `Prompt pipelines` `Code generation`

### 02 / Can a current waveform help reveal a power-line fault?

**[SERA](https://github.com/Ankitprajapati24/sera_dashboard_main)** is an IoT and edge-AI prototype for high-impedance fault detection in low-voltage power lines. I led development, designed an LSTM-based model for waveform analysis, and tested the detection logic using simulated fault scenarios.

**Winner · Smart India Hackathon 2025 · KSEBL · Problem Statement 25063**

`Edge AI` `IoT` `LSTM` `Waveform analysis`

### 03 / Can a hand gesture become text and speech?

**[SignEcho](https://github.com/Ankitprajapati24/SignEcho)** brings computer vision into a sign-language translation web application. I combined CNNs, hand tracking, and text-to-speech to translate gestures into written and spoken output.

`PyTorch` `MediaPipe` `OpenCV` `CNNs` `Text-to-speech`

## On my research desk

At **IIT Madras**, I'm working under **Prof. Rahul H. Meshram** in the Department of Electrical Engineering, as an undergraduate research intern **since July 2026**.

The question I'm exploring: **how does an agent learn which action to take next?**

I'm implementing value iteration, policy iteration, and Q-learning for Markov decision processes. My Python grid-world experiments compare dynamic programming with model-free learning, using TensorBoard to track convergence and policy performance.

Earlier, in **2025**, I contributed **AI agent prototypes to Klover.ai's open-source initiative**, taking part in team meetings and iterative development assignments.
